# Vendored: PersonaPlex fork of `moshi`

Third-party code, vendored so that nothing is fetched from another code repository. This is NVIDIA's
PersonaPlex fork of Kyutai's `moshi` package (Mimi codec, the LM and its streaming generator, the
loaders), imported as `contextspan.moshi`. Licenses: `LICENSE.moshi`, `LICENSE.audiocraft`,
`LICENSE.personaplex` in this directory. Not restyled or translated with the rest of the repository;
changes here are limited to what the fork needs to run inside this package.
